## 📌 Motivation for the Project

This project was developed as part of the **CAMPUS x Machine Learning** course framework. The primary goal was to understand how APIs function and how they can be used to deploy Machine Learning models. 

By converting a machine learning solution into an API service, we can:

- Make the model easily accessible to other applications or services.
- Integrate ML models into real-world products.
- Understand the deployment pipeline, including data handling, response formatting, and endpoint design.

This hands-on project helped reinforce the concepts of ML model serving and provided valuable experience with API development and deployment.
