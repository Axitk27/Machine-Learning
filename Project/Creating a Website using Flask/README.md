## 📌 Motivation for the Project

This project was created as part of the **Machine Learning course at Campus X** to help learners understand how to build and deploy a web application using the **Flask** framework.

By completing this project, you will gain the following skills:

- A foundational understanding of how web applications function.
- Basic knowledge of **HTML** and **CSS** for front-end development.
- The ability to deploy a **machine learning model** into a real-world web environment.
